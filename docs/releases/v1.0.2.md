# Bucket Mount 1.0.2

This release makes synchronization problems easier to diagnose and fixes a folder lock that could prevent synchronization from recovering.

## Improvements

- **Sync issues dialog:** Open **Details** in Connections to see affected files and folders, recovery instructions, and technical error details. The dialog updates automatically as issues clear.
- **Recovery actions:** Retry immediately, resume paused synchronization, show the affected item in Explorer, or copy its details for troubleshooting.
- **Clearer lock status:** Temporary file locks show **Waiting for file access** and retry automatically. Locks that persist across retries for a minute change to **Needs attention**.

## Fixes

- Release the directory scanner's own handles before converting folders to Cloud Files placeholders, preventing repeated sharing violations even when no other application is using the folder.
- Continue synchronizing unrelated files when an item is busy. Suspend remote deletions until a complete scan succeeds so unscanned or renamed files retain their remote contents.
- Include the affected path and underlying Windows error in synchronization diagnostics.
- Honor pause and immediate retry requests while reconnecting. Stopped connections explain when **Save and apply** is required.

## Downloads and updating

Choose the installer or portable ZIP for your PC:

| Architecture | Installer | Portable ZIP |
| --- | --- | --- |
| Intel / AMD x64 | `bucket-mount-1.0.2-windows-x64-setup.exe` | `bucket-mount-1.0.2-windows-x64-portable.zip` |
| Windows on ARM | `bucket-mount-1.0.2-windows-arm64-setup.exe` | `bucket-mount-1.0.2-windows-arm64-portable.zip` |

Each download has a matching `.sha256` checksum file. Quit Bucket Mount before updating. Existing settings and synchronized files are preserved by the installer.
